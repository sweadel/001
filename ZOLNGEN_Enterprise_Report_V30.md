### 🌟 Executive Summary / الملخص التنفيذي
**English:**
ZOLNGEN Enterprise Pro is a state-of-the-art, no-backend B2B ecosystem designed for institutional high-volume procurement. It bridges the gap between luxury aesthetic and industrial functionality. The platform empowers both institutional clients and administrators with 43 high-level features running entirely on a localized, high-performance database engine.

**عربي:**
نظام ZOLNGEN Enterprise Pro هو منظومة B2B متكاملة ومتطورة، صُممت خصيصاً لعمليات التوريد المؤسسي الضخمة. تجمع المنصة بين جمالية التصميم الفاخر والوظائف الصناعية القوية، حيث توفر للمؤسسات والمديرين 43 ميزة احترافية تعمل بالكامل على محرك قواعد بيانات محلي فائق الأداء.

### 🛡️ Core Pillar 1: Institutional Storefront (The Client Portal)
### الركيزة الأولى: بوابة المؤسسات والعملاء

1. **Premium Aesthetic (Glassmorphism):** High-end visual language with blurred surfaces and vibrant gold accents.
   - *واجهة Glassmorphism الفاخرة: لغة بصرية متطورة تعتمد على الأسطح الزجاجية واللون الذهبي الملكي.*
2. **Institutional Auth:** Secure login for employees with automated entity detection.
   - *نظام تسجيل دخول المؤسسات: نظام آمن للموظفين مع التعرف التلقائي على الجهة التابعة.*
3. **Advanced Product Catalog:** 3D-like hover effects and deep interaction cards.
   - *الكتالوج المؤسسي المطور: تأثيرات تفاعلية ثلاثية الأبعاد لكل منتج.*
4. **Hardware Configurator:** Real-time spec upgrades (RAM/SSD) with price calculation.
   - *نظام تخصيص المواصفات: ترقية الرامات والهاردات مع تحديث السعر فورياً.*
5. **Advanced Filters:** Search by price range, RAM capacity, and category.
   - *فلاتر البحث المتقدمة: البحث عبر نطاق السعر، سعة الذاكرة، والتصنيف.*
6. **Smart Volume Discounts:** Automatic 10% reduction for bulk institutional orders.
   - *خصومات الكميات الذكية: تطبيق تلقائي لخصم 10% عند طلب 5 أجهزة فأكثر.*
7. **B2B Coupon System:** Institutional codes (e.g., JU2024) with conflict-resolution logic.
   - *نظام الكوبونات المؤسسية: دعم الأكواد الترويجية بذكاء حسابي متطور.*
8. **Wishlist System:** Permanent storage for potential procurement items.
   - *نظام المفضلة: تخزين الأجهزة المرغوبة للرجوع إليها لاحقاً.*
9. **Invoice Archive (My Orders):** Full history of past B2B interactions and invoices.
   - *أرشيف الفواتير (طلباتي): سجل كامل لكافة التعاملات السابقة للمؤسسة.*
10. **Printable Invoices:** Generate professional PDF invoices with a single click.
    - *طباعة الفواتير: توليد ملفات PDF احترافية للفواتير بضغطة زر.*
11. **PDF Quote Generation:** Instantly turn a cart into a formal price quote.
    - *توليد كشوفات الأسعار: تحويل السلة إلى عرض سعر رسمي بصيغة PDF.*
12. **Real-time Order Tracking:** Visual progress bars for every stage of the order.
    - *تتبع الطلبات اللحظي: شريط تقدم متحرك يوضح حالة الطلب بدقة.*
13. **Maintenance Ticketing:** Dedicated portal for reporting hardware issues.
    - *بوابة تذاكر الصيانة: واجهة مخصصة لفتح بلاغات الدعم الفني.*
14. **Urgency/SLA Selection:** Define priority (High, Medium, Low) for maintenance.
    - *تحديد درجة الأهمية: اختيار مستوى الاستجابة المطلوبة (SLA).*
15. **Dark/Light Mode Sync:** System-wide theme switching with persistence.
    - *الوضع الليلي والنهاري: تبديل سمة الموقع بالكامل مع حفظ الإعداد.*
16. **Scroll Progress Bar:** Visual indicator for long catalog browsing.
    - *شريط تقدم التصفح: مؤشر علوي ذهبي يوضح نسبة قراءة الصفحة.*
17. **Spam Protection:** Integrated cooldown timer between order submissions.
    - *الحماية من السبام: مؤشر زمني يمنع تقديم الطلبات المتكررة بسرعة.*
18. **Animated UI Particles:** Dynamic background interaction for a premium feel.
    - *تأثيرات الجزيئات المتحركة: خلفية تفاعلية تعزز الشعور بالفخامة.*

### ⚙️ Core Pillar 2: Command Center (Admin Dashboard)
### الركيزة الثانية: مركز القيادة (لوحة تحكم المدير)

19. **Live System Monitor:** Real-time stats, clock, and active orders counter.
    - *مراقب النظام الحي: إحصائيات لحظية، ساعة دقيقة، وعداد للطلبات النشطة.*
20. **Interactive Analytics:** Chart.js powered revenue and profit growth trends.
    - *التحليلات التفاعلية: رسوم بيانية لنمو المبيعات والأرباح عبر Chart.js.*
21. **Multi-Level Order Approval:** Approve, Reject, Ship, and Deliver workflow.
    - *إدارة الطلبات متعددة المراحل: (موافقة، رفض، شحن، تسليم).*
22. **Inventory Management:** Full CRUD operations for all hardware products.
    - *إدارة المخزون الشاملة: إضافة، تعديل، وحذف المنتجات بسهولة.*
23. **Low Stock Alerts:** Red visual badges for products below critical thresholds.
    - *تنبيهات نقص المخزون: إشارات حمراء للمنتجات التي أوشكت على النفاد.*
24. **Bulk Product Deletion:** Clean up inventory by selecting multiple items.
    - *الحذف المجمع للمنتجات: تنظيف المخزون عبر تحديد عدة أصناف وحذفها.*
25. **Export Inventory CSV:** One-click CSV generation for warehouse audits.
    - *تصدير المخزون لملف CSV: كشوفات فورية للمخزون بصيغة أكسل.*
26. **Export Orders CSV:** Detailed interaction logs for accounting purposes.
    - *تصدير الطلبات لملف CSV: سجلات كاملة للمبيعات للقسم المحاسبي.*
27. **Revenue Goal Tracker:** Visual KPI bar against the 50,000 JOD monthly target.
    - *متتبع الأهداف المالية: مؤشر بصري لتحقيق الهدف الشهري (50 ألف دينار).*
28. **SLA Breach Monitoring:** Automatic red highlight for tickets older than 24h.
    - *مراقب الـ SLA: تنبيه تلقائي للتذاكر التي تجاوزت 24 ساعة دون حل.*
29. **Maintenance Management:** Resolve or print technical support tickets.
    - *إدارة الصيانة: حل تذاكر الدعم الفني أو طباعتها ورقياً.*
30. **Bulk Close Tickets:** Close all open technical issues in one batch.
    - *الإغلاق المجمع للتذاكر: إنهاء كافة البلاغات المفتوحة بضغطة واحدة.*
31. **Admin Internal Notes:** Secure, localized notepad for manager reminders.
    - *المذكرات الداخلية للمدير: مفكرة آمنة لتخزين الملاحظات الخاصة.*
32. **New Order Sound Alerts:** Audio ping using Web Audio API for incoming B2B orders.
    - *تنبيهات الطلبات الصوتية: جرس إنذار فوري عند وصول أي طلب توريد.*
33. **Entity Tracker:** Monitoring order volume and spend per institution.
    - *مراقب الجهات: تتبع عدد الطلبات وحجم الإنفاق لكل جامعة ومؤسسة.*
34. **Action Audit Log:** Traceable history of all administrative movements.
    - *سجل التدقيق العملياتي: توثيق كامل لكافة حركات المدير داخل النظام.*
35. **Dynamic Branding Engine:** Change store name and primary color globally.
    - *محرك الهوية الديناميكي: تغيير اسم المتجر واللون الأساسي للنظام فوراً.*
36. **Auto-Lock Security:** System-wide lockout after 5 minutes of inactivity.
    - *القفل التلقائي: تأمين لوحة التحكم بعد 5 دقائق من الخمول.*
37. **System Backup (JSON):** Export the entire local database to a JSON file.
    - *النسخ الاحتياطي: تصدير قاعدة البيانات المحلية بالكامل لملف JSON.*
38. **System Restore (JSON):** Instant database restoration from a backup file.
    - *استعادة النظام: استرجاع كافة البيانات والطلبات من ملف خارجي.*
