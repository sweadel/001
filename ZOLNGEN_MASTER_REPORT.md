### 🛠️ Technical Architecture / البنية التقنية

**[EN]**
- **Frontend:** Vanilla HTML5 / Tailwind CSS / ES6+ JavaScript.
- **Visuals:** GSAP for animations, Three.js for 3D, Chart.js for analytics.
- **Backend:** Python 3.x (server.py) for institutional orchestration.
- **State:** Decentralized database.js for persistent local logic.
- **Bilingual:** Centralized i18n.js engine with dynamic RTL/LTR support.

**[AR]**
- **الواجهة الأمامية:** HTML5 / Tailwind CSS / Vanilla JS.
- **البصريات:** مكتبة GSAP للتحريك، Three.js للرسوم ثلاثية الأبعاد، Chart.js للتحليلات.
- **الواجهة الخلفية:** بايثون 3.x لإدارة العمليات المؤسسية.
- **قاعدة البيانات:** ملف database.js اللامركزي لضمان استمرارية البيانات.
- **اللغات:** محرك i18n.js للتبديل اللحظي بين العربية والإنجليزية ودعم الاتجاهات.
