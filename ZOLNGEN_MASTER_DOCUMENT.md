### 💻 Technical Architecture | البنية التحتية التقنية

**[EN]**
- **Vanilla JS Core:** Maximum speed, zero external library bloat.
- **Localized DB Engine:** Robust persistence through `database.js`.
- **CSS3 Variables:** Dynamic theme switching (Dark/Light/Institutional).
- **Cross-Tab Sync:** Real-time data freshness across all open windows.

**[AR]**
- **جوهر البرمجة الخام (Vanilla JS):** أقصى سرعة ممكنة بدون مكتبات خارجية ثقيلة.

- **متغيرات CSS3:** تبديل السمات (داكن/فاتح/مؤسسي) بشكل لحظي وديناميكي.
