# ZOLNGEN Enterprise Pro (v26.0) 🚀

## 🇬🇧 English Overview
ZOLNGEN Enterprise Pro is a premium B2B (Business-to-Business) eCommerce platform and Command Center. Designed exclusively for institutional hardware supply, it features a state-of-the-art Glassmorphism UI, a robust LocalStorage database, and an integrated Admin Dashboard.

### Core Features:
- **Premium Storefront**: Dark/Light mode toggle, animated particles, and a cinematic hero section.
- **Advanced Product Catalog**: Quick View modal, hardware configurator (RAM/SSD upgrades), and category filtering.
- **Smart Cart System**: Real-time volume discount engine (10% off for 5+ items) and PDF quote generation.
- **Admin Command Center**: Real-time clock, sales analytics, inventory management, and one-click data backups.
- **Maintenance Portal**: Dedicated ticketing system for post-purchase institutional support.
- **Premium UX**: Custom glassmorphism toast notifications, pop animations, and silky-smooth page transitions.

### 📝 Next Steps & Requirements (Pending Configuration)
To unlock the platform's full potential, the following external integrations are required:
1. **Cloud Database Sync**: Need **Firebase Configuration Keys** to migrate from local storage to real-time cloud data.
2. **Automated Emails**: Need an **EmailJS Account (Service ID & Public Key)** to send automated order confirmations and ticket updates.
3. **Smart AI Assistant**: Need an **OpenAI API Key** or **Tawk.to Snippet** to activate the 24/7 automated support chatbot.

## 🇸🇦 نظرة عامة (عربي)
نظام **ZOLNGEN Enterprise Pro** هو منصة توريد مؤسسية متكاملة ولوحة قيادة متطورة (B2B). صُممت المنصة حصرياً لتوريد الأجهزة التقنية للمؤسسات والجامعات، وتتميز بواجهة فاخرة (Glassmorphism)، وقاعدة بيانات محلية قوية، ولوحة تحكم إدارية احترافية.

### الميزات الأساسية:
- **واجهة العميل الفاخرة**: دعم الوضع الداكن/الساطع، تأثيرات الجزيئات المتطايرة، وانتقالات سينمائية للصفحات.
- **الكتالوج المتطور**: شاشة معاينة سريعة، ميزة تخصيص الأجهزة (ترقية الرام)، وفلترة ذكية.
- **سلة الطلبات الذكية**: محرك خصم كميات تلقائي (خصم 10% لـ 5 أجهزة فأكثر)، وتوليد كشوفات أسعار PDF.
- **مركز القيادة الإداري**: ساعة حية، تحليل مبيعات، إدارة مخزون، ونسخ احتياطي للبيانات بضغطة زر.
- **بوابة الصيانة**: نظام تذاكر مخصص للدعم الفني المؤسسي بعد الشراء.
- **تجربة مستخدم استثنائية (Premium UX)**: إشعارات زجاجية مخصصة، وحركة تفاعلية سلسة (60FPS).

### 📝 الخطوات القادمة والمتطلبات (قيد الانتظار)
للوصول بالمنصة إلى أقصى إمكانياتها، يرجى تزويدنا بالمعلومات المفقودة التالية لتفعيل الميزات المتبقية:
1. **الربط السحابي (Firebase)**: نحتاج إلى **مفاتيح إعداد Firebase** لنقل البيانات من المتصفح إلى سحابة حقيقية تعمل بين جميع المستخدمين.
2. **البريد الآلي (EmailJS)**: نحتاج إلى **حساب EmailJS (Service ID & Public Key)** لبرمجة إرسال رسائل تأكيد الطلبات وحالة التذاكر تلقائياً.
3. **المساعد الذكي (AI Chatbot)**: نحتاج إلى **مفتاح OpenAI API** أو **كود Tawk.to** لتفعيل بوت الدعم الفني الذكي على مدار الساعة.
